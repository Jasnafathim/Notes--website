**Notes Website**

A simple and user-friendly Notes Website built using HTML, CSS, and JavaScript.

The website allows users to create, edit, and delete notes. Notes are automatically saved in the browser using Local Storage.

## Features

- Create new notes
- Edit notes
- Delete notes
- Save notes using Local Storage
- Notes remain available after refreshing the browser
- Simple and clean user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## How It Works

When the user clicks the Create Notes button, JavaScript dynamically creates an editable note.

The notes are saved in the browser using Local Storage.
